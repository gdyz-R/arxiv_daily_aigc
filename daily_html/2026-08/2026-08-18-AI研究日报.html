KV Cache & Inference Memory

把 KV 压缩改写为“注意力失真最小化”

AATC 不再把缓存张量的重建误差当作最终目标，而是在白噪声量化假设下直接刻画误差如何穿过注意力机制，并以变换编码与反注水进行按重要性分配的比特预算。

背景与痛点

自回归解码需要保留历史 token 的键和值，KV Cache 因而随上下文长度增长，成为长上下文推理的显存瓶颈。已有量化方法通常以缓存张量本身的重建误差为优化对象，并倾向于统一采用较低精度；但键的误差会影响注意力权重，值的误差会影响加权聚合结果。因而，“缓存误差小”并不自动推出“注意力输出失真小”。本文从这一信息流错位出发，改变了压缩目标函数。

核心创新

  • 将优化目标从缓存自身的重建误差转为注意力感知失真：论文在白噪声量化模型下证明，期望注意力感知失真可分解为键、值两类加性贡献，且可在 token 与通道维度上因子化。
  • 将该分解接入经典变换编码与反注水框架：在校准集上，AATC 按各成分对注意力失真的贡献分配比特，而非对整个 KV Cache 施加统一精度。
  • 方法成立的关键前提并不可省略：量化误差的白噪声建模以及校准集对部署分布的代表性，决定了理论分解与实际码率分配是否仍然对齐。

实验结论

论文在 Llama-3.1-8B-Instruct 与 Qwen-2.5-7B-Instruct 上，覆盖 LongBench、RULER、GSM8K、MMLU-Pro 和 MATH-500 评测。摘要报告，AATC 在约 5.8× 压缩下达到近乎无损的准确率，而每个基线都至少在部分设置中出现退化。这支持“以注意力失真而非缓存误差配置码率”的方向；但摘要未给出压缩/重建额外时延、校准代价或不同工作负载下的服务吞吐，因此不能直接将准确率结论外推为端到端推理收益。

PagedAttention：不压缩信息，先消除 KV 内存的分配浪费

经典知名论文KV CacheServing

PagedAttention 的第一性原理不同于量化：它主要处理动态请求下的碎片与重复副本，而非以低精度交换缓存信息；这使 KV 优化同时具有“失真—码率”和“分配—共享”两条正交路径。

问题背景

高吞吐服务必须并发批处理更多请求，但每个请求的 KV Cache 很大，且会随生成过程动态增长或释放。若内存管理不当，碎片和跨请求重复存储会吞噬可用于批处理的容量，进而限制吞吐。该问题的本质不是某个 token 的 KV 信息是否可删减，而是已有缓存能否以低浪费方式被放置、扩展和复用。

方法与贡献

  • 提出受操作系统虚拟内存与分页启发的 PagedAttention，并据此构建 vLLM，使 KV Cache 的动态管理面向低浪费而非静态预分配。
  • 支持请求内部及请求之间的 KV Cache 灵活共享，直接针对重复副本这一容量损耗来源。
  • 从机制上看，该路线保留缓存表示本身，主要改善有效可用显存比例；它与注意力感知量化并非替代关系，而可被视为系统层与表示层的不同优化坐标。

实验与结论

摘要报告，相比 FasterTransformer 和 Orca 等当时系统，vLLM 在相同延迟水平下将热门 LLM 的吞吐提高 2—4 倍；序列更长、模型更大、解码算法更复杂时，提升更明显。该结论直接支撑动态分页和共享对服务容量的价值，但其比较对象与评测配置属于论文报告范围，不能据此推断任意部署环境中的固定收益。
